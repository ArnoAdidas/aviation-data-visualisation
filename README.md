# Aviation Data Visualisation

## Overview
An ongoing university project focused on exploring aviation data using R.

## Objectives
- Clean and prepare the dataset for analysis.
- Explore patterns, trends and relationships in the data.
- Apply statistical methods to investigate the dataset.
- Create visualisations using ggplot2.
- Interpret and communicate the findings.

## Tools
- R
- RStudio
- ggplot2

## My Contribution
I am taking primary responsibility for data preparation, exploratory data analysis, statistical methods, visualisation and interpretation of results, as well as preparing the project presentation.

## Project Status
Work in progress. Further analysis, visualisations and findings will be added as the project develops.
